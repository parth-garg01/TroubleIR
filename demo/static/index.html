03 — How It Works

From complaint to deeplink.

Seven stages, end-to-end. Each stage is independently testable and produces a typed artifact that the next stage consumes.

Pipeline architecture Cold path
1. Query Enrichment
LLM generates 10 canonical paraphrases for broad cache coverage.
2. Semantic Cache Lookup
Checks atom-level cache. Polarity guard rejects bright vs. dim conflation.
3. SIIS Retrieval
BM25 + dense hybrid search over Samsung support knowledge base.
4. Structure Extraction
LLM extracts Goal/Action/StepGroup from SIIS evidence. Outputs typed JSON.
5. Deeplink Binding
Maps each action to catalog URI. Rejects parent-menu matches (E310).
6. Grounding Validation
Token overlap check: every step must trace to SIIS source. E204 on failure.
7. Output Lint + Cache Store
Schema, ordering, URL-leak, score checks. Plan stored with dependency map.
